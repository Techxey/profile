任何模块留空（[] 或空字符串），页面上就整块隐藏 —— 导航、底部 Tab、锚点一起消失，不会留下空卡片。所以「还没有作品」不需要删代码，留空即可。

模块与顺序

页面顺序 = settings.sections 数组顺序，导航与底部 Tab 自动跟随。每条里的 enabled 控制显隐，nav / title / desc 是导航文字、模块标题与副标题，都可以改成你自己的说法（比如把「校园实践」改成「实习经历」）。

URL 参数

参数作用场景
?edit=1直接打开编辑器发给朋友填写
?nosplash=1跳过开屏调试
?splash=1强制重播完整开屏演示
?splash=hold停在开屏终态看设计稿
?theme=dark固定深色 / 浅色分享固定外观

发布到 GitHub Pages

  1. 把整个目录推到 GitHub 仓库（index.html 与 assets/ 同级）
  2. 仓库 Settings → Pages → Source 选默认分支、目录选 / (root)
  3. 等一两分钟，访问 https://techxey.github.io/profile/

发布前建议在编辑器「品牌与开屏」里关掉「显示编辑入口」，访客就看不到铅笔按钮了。
